# 模型駅 · N Gauge Platform Board

[在线体验](https://n-gauge-platform-board.clear-seal-8717.chatgpt.site/) · [班次来源与范围](TIMETABLES.md) · [代码许可](LICENSE)

面向 N 比例铁路模型和 iPad 的日本铁路站台发车标模拟器。纯 HTML / CSS / JavaScript，无框架、无需安装依赖。

![iPad 横屏预览](docs/images/ipad-landscape.jpg)

JR东日本风格的N比例模型站台屏：1站台外圈R315，2站台内圈R282。237个车辆/服务预设，按地区 → 类型 → 线路 → 车辆选择。保留LCD/LED外观、品牌与设备图标、手动节数、行先和底部滚动案内。

## 这一版：官方固定参考班次

固定参考日为 **2026-10-25，星期日，日本时间JST**，共425条可选参考。每预设挑选一班或数班；每条记录都有真实出发站、时间、终点、号数（官网有才填写）、来源和核对状态。不是一个车站的全天时刻表，也不提供实时运行或余席。

| 预设数 | 核对范围 |
|---:|---|
| 117 | 已核对10/25运行日或当天时刻源 |
| 95 | 官方现行土休日参考 |
| 15 | 官方每日时刻参考 |
| 4 | 观光列车官方时刻，具体运行日仍需确认 |
| 2 | 银座、丸之内的官方旧表，9/19改正后现行时间未确认 |
| 2 | 北斗星、超级白鸟：已停运的官方历史参考 |
| 2 | 湘南、赤城：周日不运行，保留工作日参考 |

车辆系列可能混用。班次来源真实，不等于指定系列当日一定担当该班。编组继续按模型的1～30节设置，实际车站番线不会覆盖模型1/2站台。

右上角 `···` → 选择车辆 → **参考班次**。切换参考时同步出发站、时间、车次和行先；也可直接修改固定时间。修改会标为“已手动调整”，按车型保存在当前浏览器，切走再选回来仍保留。恢复所选参考可回到原始值。

**旧四行和自定义编组不会自动覆盖。** 更新后点击“四行套用默认参考班次”才统一切换；这会覆盖当前四行的参考字段。载入场景也会使用参考班次，并保留已记忆的自定义时间和节数。不同设备的浏览器存储不互通，可导出JSON设置备份。

全部来源与筛选记录：网页 `timetable.html`；逐项说明 `TIMETABLES.md`。银座/丸之内的旧表警示在编辑器和核对页均明确显示，没有冒充今天的正式班次。

## 滚动停站与座席

底部依次显示番线、时间、列车名、行先、停站与座席。已录入完整停站且号数/方向/种别仍与参考一致时显示该班停站；只改时间可保留停站。其余为线路主要停站或各站停车说明。手填一个新号数不会联网查询另一班。

每班“滚动停站与座席”可自定义完整停站、出发站和座席。座席号车按已核对的实车编组显示，模型节数不符时改为类别说明。E6/E8保留实车11～17号车编号；私铁收费指定席与免费特急分别处理。周日Wing Seat仅专用车指定席，ながまれ普通运用按一般车处理。

最近待发时刻默认按日本当前时钟每日循环，支持跨午夜、指定模型时刻、固定行/站台、暂停和速度设置。参考日期始终固定10/25，不会次日自动换表。

## iPad与保存

Safari打开在线页面，推荐横屏；分享 → 添加到主屏幕。右上角隐蔽按钮打开编辑。支持浏览器允许的全屏/常亮；减少动态效果时滚动栏改为静态横向阅读。桌面浏览器已做iPad尺寸检查，未进行实体iPad Safari硬件测试。

沿用V2存储键并兼容V1，旧时间、行先、车型、节数和显示设置保留。官方参考库为静态快照，主画面不依赖外部字体、CDN或在线时刻API。

## 本地运行

```powershell
python -m http.server 8769 --bind 127.0.0.1 --directory dist
```

本机打开 http://127.0.0.1:8769/ 。部署到模型桌的电脑/开发板时，让服务器监听局域网地址，iPad访问对应IP。

- `CATALOG.md`、`SPECIAL-DISPLAYS.md`、`SCROLL-RESEARCH.md`：既有考证与来源。

## 开发与部署

需要 Python 3（本地静态服务器）和 Node.js 20 或更新版本（运行检查）。页面运行本身不依赖 Node.js。

```sh
npm test
python -m http.server 8769 --bind 0.0.0.0 --directory dist
```

iPad 与运行服务器的设备连接同一局域网，Safari 打开 `http://设备局域网IP:8769/`。也可把 `dist/` 内容部署到任意静态网站托管服务。使用仓库子路径托管时，相对资源路径可正常工作。

GitHub Actions 会在 push 和 pull request 时运行三组现有检查，无需第三方运行时依赖。

本仓库发布的是已运行的 V6 快照：237 个预设、425 条代表班次。**全天班次库仍在整理中，当前版本不是每车型的完整全天时刻表。** 已暂停的扩展资料保留在开发工作区，尚未合入本发布版本。

后续方向：完整站别/方向班次、按出发站与时段筛选、视觉识别输入、与 LVGL 硬件显示端对接。目前这是可独立使用的网页前端。

## 贡献

欢迎通过 Issue 或 Pull Request 提交界面改进、资料纠错和更多时刻。修改时刻请附运营商官方来源、适用日期、出发站和方向；不要把混用线路的时刻写成某个车辆系列的保证运用。编组节数以模型设置为准。

提交前运行 `npm test`；修改界面时请同时检查 iPad 横屏和竖屏，确保右上角编辑入口可操作。
